# Dilshod Portfolio

Backend, AI va Full Stack Developer portfolio — Python, FastAPI, Django, AI Chatbots, va avtomatlashtirish tizimlari.

## 🚀 Texnologiyalar

- **Frontend**: React 18 + Tailwind CSS + Vite
- **Icons**: Lucide React
- **Fonts**: Space Grotesk, Inter, JetBrains Mono
- **Build**: Vite
- **Deploy**: Vercel

## 📦 Yuklash va Ishlatish

### O'rnatish
```bash
npm install
```

### Lokal Develop
```bash
npm run dev
```
Brauzer avtomatik ochiladi `http://localhost:3000` da.

### Build
```bash
npm run build
```
Natija `dist/` folderde saqlanadi.

### Vercelga Deploy
```bash
npm run deploy
```

## 📁 Struktura
```
portfolio/
├── src/
│   ├── main.jsx           # Entry point
│   ├── App.jsx            # Main App component
│   └── globals.css        # Global styles
├── index.html             # HTML template
├── vite.config.js         # Vite configuration
├── tailwind.config.js     # Tailwind configuration
├── postcss.config.js      # PostCSS configuration
├── vercel.json            # Vercel deployment config
└── package.json
```

## 🔧 Konfiguratsiya

- **Vite**: `vite.config.js` 
- **Tailwind**: `tailwind.config.js`
- **Vercel**: `vercel.json`
